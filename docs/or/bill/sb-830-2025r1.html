What the bill does (OR measure summary (OLIS plain-language digest + catchline))

This Act changes laws for the on-site septic system loan program to allow for grants and to expand who qualifies for help. Modifies provisions of the on-site septic system loan program to allow for grants. Expands eligibility for the program. Takes effect on the 91st day following adjournment sine die.
