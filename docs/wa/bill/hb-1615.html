HB 1615 · Water system classifications

Bars using a default people-per-connection number to classify a public water system as Group A when that would move it from Group B.

What the bill does (WA House Bill Report (Summary of Bill))

A default number of people per service connection may not be used to determine the number of individuals served by a public water system if doing so would change the system’s classification from Group B to Group A.
